# Portfolio website (HTML + CSS + JavaScript)

Open `index.html` in any browser. No server or build step needed.

## Change content
Edit **js/data.js** only (plain text, well commented). Save and refresh the browser.
- Edit any text; add or delete items inside lists (projects, jobs, skills, certifications, stats...).
- Delete a block (or empty its list) and that section and its menu link disappear.
- Colours: change the four values in `theme` at the top of data.js.
- Resume PDF: replace `assets/resume.pdf` (same file name).
- LinkedIn: paste your full URL into `linkedinUrl` to make it clickable.

## Publish for free
Upload the whole folder to Netlify Drop, GitHub Pages, or Cloudflare Pages. Share the link with HR.
`Print Resume` uses the browser print dialog (choose "Save as PDF").
